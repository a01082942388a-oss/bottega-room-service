카테고리 순서

카테고리 자체의 노출 순서를 드래그로 변경할 수 있습니다.

카테고리를 잡아서 좌우 순서를 바꾼 뒤 아래의 전체 순서 저장을 누르면 메뉴 순서와 함께 저장됩니다.

메뉴 순서 / 품절 관리

☰ 아이콘으로 메뉴 순서를 바꾸고, 메뉴를 더블클릭하면 상태 관리창이 열립니다.

드래그: 메뉴 순서 변경 · 더블클릭: 이름수정 / 가격수정 / 숨김 / 품절 기간 설정

전체 페이지

주문페이지의 기본 글씨체, 글씨색, 배경색과 배경사진을 설정합니다.

등록된 배경사진이 없습니다.

BOTTEGA 간판

상단 BOTTEGA 간판의 배경, 글씨체와 글씨색을 설정합니다. 배경사진이 등록되어 있으면 배경색 위에 사진이 표시됩니다.

등록된 간판 배경사진이 없습니다.

언어 선택 버튼

한국어 · ENGLISH · 日本語 · 中文(简体) 언어 버튼의 글씨체, 글씨크기와 글씨색을 설정합니다.

버튼 / 카테고리

주문페이지의 선택된 카테고리와 주요 버튼 색상을 별도로 설정할 수 있습니다.

실시간 확인

설정을 저장하면 주문페이지에도 적용됩니다. 미리보기는 저장 후 자동으로 다시 불러옵니다.
